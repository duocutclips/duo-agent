# Winning hooks

The clip-analyst rewrites this file each week from data/clip-log.csv. Until there is data, these are starting patterns to test, not proven results:

- Open on a number: "I lost $40,000 in one week"
- Open on a question the viewer can't answer: "Why do rich people never do this?"
- Open on a confession: "I've never told anyone this"
- Open on disagreement: "Everyone is wrong about..."
- Open mid-reaction: laughter, shock, an argument already happening
